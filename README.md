# Asset Snap

一个轻量、本地优先的宏观资产快照工具，用来定期记录净资产变化。

Live Demo：[snap.closeai.moe](https://snap.closeai.moe)

## 它适合做什么

Asset Snap 不追踪每一笔流水，而是让你每隔几天记录一次完整的财务状态：账户余额、负债、投资浮盈/浮亏和备注。它更适合回答这些问题：

- 我现在的净资产是多少？
- 最近一次记录以来变化了多少？
- 资产、负债、投资和现金分别占多少？
- 某次市场波动、发薪、还款之后，整体资产有什么变化？

## 主要功能

- 账户管理：支持资产、负债，以及现金/存款、投资、信用/消费贷、长期贷款分类。
- 快照录入：按账户自动生成录入表单，并默认沿用上一次余额。
- 投资浮盈/浮亏：投资账户可选填浮盈或浮亏；留空时会沿用上一次数据。
- 总览面板：展示净资产、总资产、总负债、变化、投资账面、浮盈/浮亏、成本估算等指标。
- 趋势图：支持切换查看净资产、资产/负债、浮盈/浮亏趋势。
- 历史记录：按日期查看快照、变化和备注。
- 数据导入导出：通过 JSON 文件备份和恢复。

## 数据与隐私

这是一个 local-first 应用。数据默认只保存在浏览器本地存储中，不依赖云数据库或外部服务。

请定期使用「导出 JSON」备份数据，尤其是在清理浏览器缓存、换设备或重装系统之前。

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```
